# 💈 33 Barber Crew

**Site institucional e funcional desenvolvido para a barbearia "33 Barber Crew", com foco em interatividade, agilidade e responsividade.**

---

## ✂️ Sobre o Projeto

O site da **33 Barber Crew** foi criado com o objetivo de facilitar o agendamento de serviços, divulgar a identidade da barbearia e proporcionar uma navegação fluida ao usuário em qualquer dispositivo.

O layout é moderno e responsivo, com páginas bem definidas e botões interativos que permitem ao cliente agendar um horário com apenas alguns cliques.

---

## 📱 Funcionalidades

- ✅ Botões de agendamento de serviços diretamente pelo site  
- ✅ Layout responsivo para celulares, tablets e desktops  
- ✅ Divisão clara de seções: página inicial, serviços, unidades e produtos  
- ✅ Navegação por links âncora para uma experiência fluida  
- ✅ Design intuitivo e atrativo para o usuário final
